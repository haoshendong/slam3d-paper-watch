今日概览

  • 结论先行：今天真正有分量的一篇是 PnP\*（可认证全局最优的 PnP 求解器）——它不提高平均精度，而是把“这个位姿是不是全局最优”从不可知变成可证明，正好落在我们“可靠状态估计”的底座上。其余四篇 A 级共享同一种结构：把“生成候选”和“判断/选择”分开，再给判断加一个可回滚或可解释的校验层（SAGE 的 rank fusion + 规则谓词、WorldMirror 的 typed failure + 回滚、RepresentNav 的接口学习 + 未来表征校验、EgoForesight 的可靠度加权 + 结果蒸馏）。
  • 最值得读的一篇：PnP\*。N=6 时 74 ms 给出带证书的位姿，σ≤10 px 内 40/40 次松弛精确；它的失败边界写得很清楚（N<6 无保证、有外点直接不成立），可以直接当我们前端的“全局最优性体检”。
  • 最需要打问号的一篇：WorldMirror。回放成功率 100% vs 40% 很亮，但只有 10 个场景、17 个物体，且空间指标（mask IoU 0.469、位置误差 9.66 cm）明确输给 GPT-6 Astra（0.598、8.72 cm）——“看起来像”与“摆得准”在这里是分离的。
  • 主轴映射：底层几何 = PnP\*（可认证估计）；3D/4D 表征 = RADIANT（物体中心前馈渲染，B 级）；空间推理 = SAGE（规则语义 → 候选偏好）；具身决策 = RepresentNav（导航基础模型）、EgoForesight（VLA 数据扩展）、WorldMirror（real-to-sim 世界构建）。
  • 层级口径：采集器今天几乎没有给出层级（只有 3 篇有 priority_tier），PnP\*、WorldMirror、SAGE、RADIANT 的层级与领域均为人工复核后写入 candidates.json（含 tier_review_note），评分同步调整。
