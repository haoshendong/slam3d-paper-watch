今日概览

  • 结论先行：今天的增量集中在“4D / 动态场景的表示与在线化”。四篇 S 级都围绕同一件事——如何在不做逐场景重优化的前提下处理动态：Stream4D 在流式主干的 KV cache 上做运动解耦，RayCo4D 用连续时间状态估计把断裂轨迹接起来，HiQGS 把时间戳变成查询条件，AEON 把生成模型接到显式 4D 基元上。
  • 最值得读的一篇：RayCo4D。它把“轨迹是测量、不是状态”讲清楚了，用 WNOA 过程先验补上无观测区间——这与我们处理 GNSS 失锁/弱纹理段的滑窗优化是同一个数学结构，且消融把四个模块的贡献量化到 dB 级。
  • 最需要打问号的一篇：Stream4D。正文承诺消融但 HTML 版本没有独立消融表，位姿提升只有 ATE −6.7%、RRE −1.1%，分割仍比离线 VGGT4D 低 7.7 个 IoU 点。
  • 主轴映射：底层几何 = RayCo4D（连续时间运动）、HiQGS（前馈高斯）；3D/4D 表征 = Stream4D（流式动态解耦）、AEON（4DGS 世界模型）；空间推理 = Think-Capture（符号 3D 状态进 VLM）；具身决策 = CLOSER（证据不足时主动取观测）。
