今日概览

  • 结论先行：今天没有“新范式”，三篇值得读的论文各修一个具体失效模式——GaussianSpline 修“均匀时间参数化浪费容量”，Active Reachability 修“训练数据覆盖不到可恢复边界，导致 OOD 上乐观幻觉”，EKT-Router 修“专家与证据各自独立选择导致错配”。三者共享同一种方法论：先承认某处分配/覆盖/配对是错的，再把这件事变成可学变量（时间宽度、探索目标、交互项）。
  • 最值得读的一篇：GaussianSpline。它没有加网络、没有改渲染器，只把每条高斯轨迹的区间宽度变成 softmax 上的可学参数，就在 flames 上把 PSNR 从 STG 的 23.96 拉到 27.42（+3.46 dB）；反面证据也齐全——软接触高频碰撞场景 26.84 dB，仍输 Gaussian-Flow 的 31.10。
  • 最需要打问号的一篇：GaussianSpline 的消融。Table 2 显示 K=2 非均匀（32.08）反而优于默认的 K=3 非均匀（31.74），论文没解释为何默认取 K=3；而且消融的 5 个场景与主表 Table 1 不是同一组，数字不能拼接。
  • 最像“工程可搬”的一篇：EKT-Router。路由器 + 校验器一共约 1.245M 参数（<0.02%），且“全部证据被拒就退回原始输入”在结构上精确成立——这正是门控设计里最难保证的性质。
  • 主轴映射：底层几何/表示 = GaussianSpline（运动基元的时间分辨率）；3D/4D 表征 = CVTSplat（自适应 CVT 表面重建）；空间推理 = EKT-Router（专家—证据对齐）；具身决策 = Active Reachability（可恢复性监控与回退触发）；可靠估计底座 = Active Reachability 的不确定性门限 + Bracketing 的多曝光因子图。
  • 采集口径必须记住：今天是 arXiv API 连续第 5 天失败（10-24 至 10-28）。RSS 只覆盖 5 个分类的公告，且丢失关键词检索能力，所以“今天某方向没有新论文”不能当作该方向无进展。
