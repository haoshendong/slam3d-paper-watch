Ask to Evolve（EvoLife）：混合动作空间 + 主动提问 + 持久记忆的终身具身导航框架

Ask to Evolve: A Unified Harness for Lifelong Embodied Navigation with Hybrid Action Space and Persistent Memory

Kai Sheng, Liuyi Wang, Jinlong Li, Haojie Dai, Chengju Liu, Qijun Chen

把导航做成工具化 agent：四种动作模式可切换，遇歧义主动向 guide 提问，地点记忆跨任务保留。R2R-CE 上无交互 86% SR、有交互 100% SR，记忆重访 SPL 从 82.2 升到 93.3；GOAT e-SR 94.0、LHPR-VLN 98.0。关键前提是 guide 私下可访问路线与目标信息——100% 应读作“有特权协助下的上限”，而不是自主导航水平。

方法本质拆解 · What actually changed

是不是微调？

没有训练新模型。整套系统是“工具化 harness + 现成多模态大模型”，主实验用 GPT-6 Astra（ultra），并替换 Qwen3.8-Max 与 DeepSeek V4.1-Flash 做骨干对比。所谓“进化”发生在记忆内容上：地点记录随任务累积与修订，而不是权重更新。

有没有额外约束？

约束来自接口而非损失：每子任务最多 10 次交互；成功判定用各基准的几何阈值（R2R/RxR 3 m、OVON/CoIN/GOAT 0.25 m、HM3D v2 0.1 m、LHPR 1 m）；记忆在每个序列开始时重置，序列内跨子任务保留。

推理/后端到底做了什么？

每个决策步是一次完整的 agent 循环：读观测与记忆 → 选工具（感知/导航/交互/记忆）→ 执行 → 回读结果。导航动作交给仿真器或机器人底层执行，深度来自 RGB-D 或仿真几何；没有可微优化、没有全局 BA，位姿由仿真器/机器人提供。

方法本质是什么？

本质是把“导航”重写成“带外部信息查询与持久存储的工具调用序列”：动作空间决定怎么走，交互决定何时补充信息，记忆决定信息如何跨任务留存。它没有改变底层定位与建图，改变的是决策层如何组织与复用证据。

输入（观测 + 指令 + 地点记忆）→ agent 选择四种动作之一或发起提问 → 执行并回读结果 → 把新证据写入地点记录 → 在特权 guide 协助下把成功率推到 100%，并在重访时靠记忆把 SPL 提到 93.3。

01

桥接价值Bridge

桥接价值

它回答的是“智能体什么时候该问、问完怎么用、用完怎么记”这三个工程问题，而不是再提一个导航网络。对我们可靠性主线最有价值的是它的对照结构：同一套 harness 下，把交互与记忆分别开关，就能量化“外部协助”与“历史经验”各自的边际贡献。地点记录（位姿 + 描述 + 历史图像 + 对话）其实就是一个轻量语义地图节点，可以与我们现有的地图/因子图后端对接。

02

方法与模块Method

方法摘要

EvoLife 把导航拆成工具调用循环：每步由多模态 agent 选择感知、导航、交互或记忆操作。动作空间有四种模式——选空间航点、局部离散微调、点选图像像素、指定物体接近；执行后回读真实结果再决定下一步。主动交互由 agent 自行触发（澄清指令、请求方向、请求开门等实际帮助），guide 与 navigator 使用同一骨干但在独立 session 中运行，navigator 只看到自然语言回复，每子任务最多 10 次交互。地点记录把位置与描述、观测、历史图像、对话绑定，支持跨任务检索、更新与重访。

可迁移模块

第一，混合动作空间 + 执行反馈回读：把“动作是否按预期执行”作为下一决策的输入，这个接口可以直接用于我们策略侧的动作校验。第二，place record 的字段设计（位姿、语义描述、历史图像、对话、来源时间），比纯几何地图多一层可检索语义，适合做回环候选的语义先验。第三，交互 × 记忆的 2×2 开关矩阵，是评估“外部信息 vs 历史经验”边际贡献的干净模板，可搬到我方系统做消融。

04

边界与下一步Limits & Next Step

边界与风险

最重要的边界写在实验设置里：guide “privately accesses route- and goal-related information”，navigator 只收到自然语言回复。这意味着 100% SR 是“有人/有特权信息可问”的上限，不能当作自主导航 SOTA；可比的自主数字是 86%。失败分析显示所有失败都发生在停点精度（例：停在 0.73 m，阈值 0.25 m），语义目标识别全部正确——也就是说它强在“找对地方”，弱在“停准地方”。作者承认实时性与成本限制（多轮推理 + 工具执行导致延迟与 API 费用）；真机只有 3 个任务、跨两天，属定性验证。

下一步实验

先做阈值敏感性：把成功判定从 3 m / 0.25 m 改成 0.5 m / 1.0 m 重算，看 100% 有多少是阈值宽松的产物。再做“去特权”对照：把 guide 换成只有常识先验、看不到路线与目标的模型，量化主动提问的净收益（预期会从 +14 个百分点显著缩水）。最后把 place record 接到我们的地图后端，用重访 SPL 与定位漂移两项指标检验“语义记忆”是否真的降低了对重定位精度的依赖。

原文摘要 · Abstract

要让具身智能体在真实世界里长期工作，行动、交互与记忆必须协同：每次遭遇都应影响当前决策，并沉淀为后续任务的经验。EvoLife 是一个统一的导航 harness，支持四种动作模式（航点、局部离散调整、像素导航、目标导航），允许智能体在指令模糊或受阻时主动提问求助，并用“地点记录”把观测、描述、历史图像与对话绑定到空间位置。作者在 8 个基准、4 类任务族上评测，平均每集仅 1.87 次主动交互，在 4 组 100 集任务上报告 100% 成功率，并通过跨天真机实验演示经验复用。

Giving embodied agents the freedom to act autonomously, initiate interactions, and understand their surroundings through experience is a step toward bringing them to life in the physical world. Realizing this vision requires action, interaction, and memory to work together, so that each encounter can inform current decisions and contribute experience for future tasks. We present EvoLife, a unified navigation harness that enables a multimodal embodied agent to choose how to move, when to ask, and what experience to carry forward. Its hybrid action space supports waypoint navigation, local discrete adjustments, pixel-based navigation, and object-directed navigation. Active interaction allows the agent to seek clarification or assistance when it encounters ambiguity or difficulty, while persistent spatial memory binds observations and dialogue to places, retaining useful experience to guide subsequent visits. We evaluate eight benchmarks across four task families: vision-language navigation, object navigation, interactive instance navigation, and continuous multi-task navigation. With an average of only 1.87 active interactions per episode, our method achieves a first-visit success rate (SR) of 100% across four 100-episode sets spanning vision-language navigation and object navigation. Complete-sequence SR reaches 98% on 50 LHPR-VLN sequences and 94% on 50 GOAT-Bench sequences. In the R2R revisit setting, success weighted by path length (SPL) increases from 82.23% to 93.31% with retained experience. Multi-day physical navigation further demonstrates exploration, proactive help-seeking, and revisiting remembered places. Together, these results advance the vision of bringing embodied agents to life through autonomous action, proactive interaction, and the accumulation and reuse of experience.
