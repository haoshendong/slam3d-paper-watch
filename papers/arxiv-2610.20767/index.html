Multi-Dimensional Featurizers Yield Fine-Grained Steering and Data Shaping in Robot Foundation Models

Aiden Swann, Mozes Jacobs, Mathilde Papillon, Siddharth Boppana, David Chanin, Dron Hazra, Usha Bhalla, Curt Tigges, Mac Schwager, Owen Lewis, Jack Merullo, Ekdeep Singh Lubana, Atticus Geiger, Thomas Fel, Matthew Kowal

把 VLA 激活的特征字典从「单一方向」换成「低维子空间块」（块大小 1 即退化为 SAE），并额外引入 Fisher 加权重构（用动作似然梯度构成的 Fisher 矩阵度量重构误差对输出行为的影响）。激活语料为约 5,200 万条未池化的图像/文本/状态 token（来自 45,344 个 episode），比此前最大池化语料大约两个数量级。开环操控（52 个留出场景—指令对比、6 个噪声种子）：几何站点只需 1 个 BSF 块即可复现 99.7% 的激活修复效果（SAE 也是 1 个但恢复 98.2%），语义站点 BSF 用 2.15 个块达 83.8%（SAE 3.50 个、81.9%），视觉站点 BSF 16–20 个块但留出迁移不如 SAE（88.3% vs 97.3%）。闭环语义重定向（每对 20 次、共 60 次）：BSF 用 2.3 个特征实现选择 100%、抓取 96.7%、放篮 93.3%，SAE 为 2.5 个特征 / 88.3% / 83.3% / 75.0%。数据归因：在 π0.5 第 9 层找到 3 维块 F1515 对应失败恢复，掩掉 1.38% 的 token 监督后恢复行为被显著延迟。

方法本质拆解 · What actually changed

是不是微调？——特征提取器要训练，主干策略冻结；末段有一次极小的数据整形微调

主体部分训练的是特征提取器本身（BSF/SAE 及其 Fisher 加权变体），在约 5,200 万条未池化激活上学习，VLA 主干权重保持冻结。只有在最后一节的行为整形里才出现参数更新：从 π0.5-base 出发微调，并对与 F1515 窗口重叠的 16 步动作块掩掉损失，属于一次受控的、只改变监督信号的微调，而不是架构改动。因此「几何站点 1 个块 99.7% 恢复」这类结果描述的是冻结主干上的干预能力。

有没有额外约束？——块结构先验 + 联合选择 + 按输出敏感度加权

新增约束有三层：特征被硬性组织成低维子空间块（块大小 1 即退化为 SAE），这是对表示几何的先验；块的选择是联合优化（不是逐特征独立挑），使被选集合共同解释激活；Fisher 加权重构用动作似然梯度构造的经验 Fisher 矩阵对误差二次型加权，等价于允许在「对动作无影响的零空间」内不重构。约束作用在重构目标与特征几何上，而不改变主干的前向计算。

推理/后端到底做了什么？——发现特征、施加干预、再做数据筛选

推理流程分三段：先在留出的场景—指令对比上搜索出少数几个能复现激活修复效果的特征（自动化搜索在训练集上进行，选定集合后在留出集上评测，避免挑选偏差），再把选定特征以激活编辑的方式施加到策略上（开环看首个动作块，闭环跑完整 episode），最后把特征激活反查到训练数据：以连续两帧超过阈值判定恢复窗口，对这些窗口的 16 步动作块掩掉损失。全程没有额外的优化后端或全局求解，编辑是逐次前向的激活替换。

方法本质是什么？——改变「特征的几何假设」，从而同时改变可控性与可归因性

本质是把特征字典的几何假设从「一个方向一个概念」改成「一个低维子空间一个概念」，使同一个概念内部的连续变化被保存在同一块内，因而可以用更少、更整块的编辑复现同样的行为改变；同时用 Fisher 加权把「重构得像不像」换成「重构后动作变不变」，让表示学习对齐下游行为。它没有做的是：没有解释特征如何在训练中形成，也没有证明块结构在所有指标上更优——作者明确指出 SAE 在部分量化指标上更好，收益依赖未池化语料与训练规模。

输入/先验 = 冻结的 π0.5 / MolmoAct2 / MolmoBot 主干 + 约 5,200 万条未池化激活（45,344 episode）+ 块稀疏先验与动作似然的 Fisher 矩阵；改变的位置 = 特征字典的几何（方向→低维子空间）与重构目标（等权重→按下游动作敏感度加权）；约束或合并动作 = 联合块选择 + Fisher 加权重构 + 在留出集上冻结选定特征集合后再评估；直接效果 = 几何站点 1 块复现 99.7% 的激活修复、闭环语义重定向 2.3 个特征达 93.3% 完成率、掩掉 1.38% token 即可延迟失败恢复行为。

01

桥接价值Bridge

桥接价值

本文把「特征提取器该用什么几何」变成可量化的问题，并给出两条对你直接有用的证据链：一是用极少量特征块复现激活修复效果（几何站点 1 个块 99.7%），说明内部干预的因果可以量化而不是靠个例展示；二是用特征归因把某种行为反查到训练数据（掩掉 1.38% token 即显著延迟恢复行为），说明「行为—数据」之间存在可操作的对应。对可靠状态估计与融合而言，这两个思想都可迁移：给每个注入的观测/先验一个可归因的量（它影响了哪些输出），并统计「用最少几个自由度就能复现该影响」。

02

方法与模块Method

方法摘要

方法层：把特征定义为子空间块（块大小 b=1 时退化为 SAE），联合选择块的稀疏集合并重构激活；在此基础上加入 Fisher 加权变体——用动作 token 对数似然对激活的梯度构造经验 Fisher 矩阵，把重构误差按其「对输出动作的影响」加权，从而允许在无影响的零空间里欠重构。数据层：收集约 5,200 万条未池化的图像、文本与状态 token（均匀覆盖 45,344 个 episode），显式不做跨模态池化，使不同特征结构的比较不受语料池化干扰。评价层：三项指标——激活重构、输出行为保持（教师强制下动作对数似然的变化）、以及机器人相关的因果影响与任务变量可解码性（单个特征对末端位移的消融效应与十项状态/进度变量的最佳单特征 R²）。

可迁移模块

第一，可迁移「用最少自由度复现效应」的评测方式：把干预效果相对激活修复做归一化（本文称 held-out recovery），既得到统一的量纲，也避免不同结构的特征数量不等导致的不公平比较。第二，可迁移「按输出敏感度加权重构」的思路：你的状态估计里不同方向对下游位姿/地图的影响差异巨大，Fisher 加权提示可以按下游影响而不是按数值大小来决定保留哪些分量。第三，可迁移「特征—数据段归因」流程：先用特征定位行为窗口，再只掩掉这些窗口的监督做微调，并用独立指标验证行为是否真的被移除——这可以作为你在多源数据混合训练时检查「某个能力来自哪部分数据」的通用手法。

边界与下一步Limits & Next Step

边界与风险

第一，论文正文与表 2 之间存在一处数字不一致：正文称重开时间「从 1.89 秒升到 14.25 秒、超过七倍」，而表 2 的未修改行为 3.13 秒、本文方法 12.93 秒——两个口径无法同时成立，复现时应以表 2 或官方仓库为准（待核验）。第二，作者明确承认 BSF 并非全面更优：SAE 在部分量化指标（尤其视觉站点留出迁移）上更好，块更大带来重构改善的同时也带来行为保持与迁移的权衡。第三，闭环验证只对语义重定向完成，视觉与几何干预仅在开环评估，闭环的视觉/几何操控需要跟踪运动图像区域并适应观测与机器人状态变化，尚未解决。第四，作者也承认无法说明这些特征如何产生、如何参与策略计算，且激活语料与训练规模本身对结论有贡献（更强基线提示不能只归因于几何）。

下一步实验

建议做两项最小实验。(a) 用你现有的多源观测做一个「按下游影响加权重构」的廉价版本：对融合后的残差/状态向量，用下游位姿误差的梯度估计重要方向，比较等权与加权两种降维在固定压缩率下的位姿指标，验证 Fisher 加权的收益是否在你的问题里也出现。(b) 复刻「特征—数据段—行为」链条的一个缩小版：挑一个你已知失败模式（例如某类退化场景下的异常残差），用无监督特征定位该模式在数据中的窗口，只掩掉这些窗口做一次微调，再用独立评测确认该模式是否被抑制、其他指标是否被牺牲。对照至少要包含随机掩码与同类启发式（如 kNN），否则无法把收益归因于归因方法本身。

原文摘要 · Abstract

更好的特征发现能否通过内部干预与训练数据改善对机器人行为的控制？近期在视觉与语言模型上的工作揭示了多维度特征，从而催生了块稀疏特征提取器（block-sparse featurizers, BSF）——它把每个特征表示在一个低维子空间中。本文考察这种结构是否能为视觉—语言—动作模型提供可解释的操控接口，并用于塑造其训练数据。作者表明 BSF 能够恢复模型中若干个多维度、任务相关的特征（例如感知、语言、本体感受状态、episode 阶段与控制变量），并通过细粒度操控对这些特征做因果验证：在视觉感知、语义表示与空间定位上的定向修改会产生可预测的下游动作变化。最后，作者用基于特征的数据归因定位某一具体行为（失败后的恢复）来自训练数据中的何处，发现掩掉不到 1.4% 的训练 token 就足以去除该目标行为。总体而言，结果说明把特征提取器与表示几何相匹配，可以获得更有效的理解与改变机器人行为的工具。

Can better feature discovery improve control over robot behavior through internal interventions and training data? Recent work in vision and language models reveals multidimensional features, motivating block-sparse featurizers (BSFs), which represent each feature in a low-dimensional subspace. We investigate whether recovering this structure provides an interpretable interface for steering vision-language-action models and shaping the data from which they learn. We show that BSFs recover several multi-dimensional task-relevant features underlying the model's computation (e.g., perception, language, proprioceptive state, episode phase, and control variables). We causally validate these features through fine-grained steering: targeted changes in visual perception, semantic representation, and spatial localization produce predictable changes in downstream action prediction. Finally, we use feature-based data attribution to isolate where a specific behavior (failure recovery) arises in the training dataset, identifying fewer than $1.4\%$ of training tokens whose masking is sufficient to remove the targeted behavior. Overall, our results show how matching featurizers to representation geometry can provide more effective tools for understanding and changing robot behavior.
