方法本质拆解 · What actually changed

训练

在 DG 和 VisymScenes 图像对上训练 focal loss。LoRA、camera tokens 和 MLP 是主要可训练部分。

约束

二分类约束候选边是否共享三维表面，并要求双向推理对输入顺序保持稳定。下游 SfM 再用固定的 COLMAP 或 GLUEMAP 阶段检验图完整性。

推理

两个图像顺序提取并融合 camera tokens。轻量 MLP 在 SfM 前裁剪高风险匹配边。

机制

直接利用基础模型原生跨视角 token 而非重型 pair transformer。LoRA 恢复判别信息，token compression 负责加速。

方法本质：结构化训练、观测约束、推理流程和可靠性机制共同决定结果，不能把单一模块的增益误认为完整方法效果。

01

动机与问题Motivation

动机与问题

重复建筑、相似纹理和 doppelganger 表面会产生看似合理但物理上错误的图像匹配，进而让 SfM 错误注册相机或合并不同结构。DG++ 的精度较强，但对数千图像的每条候选边都运行重 backbone 和重 classifier，运行时间成为瓶颈。

02

方法Method

方法总览

XDG 用冻结 DA3 作为几何感知 backbone，只训练 qkv/proj/fc1/fc2 上的 LoRA、camera tokens、融合模块和分类头。图像对按 A→B 和 B→A 两种顺序推理，交换视图维度后融合四个 stage 的 camera tokens，最终用小型 MLP 判断 true match 或 doppelganger。

关键技术细节

LoRA rank=8、alpha=16、dropout=0.05，四个 DA3 stage 的 camera token 维度为 1536；双向 token 通过共享两层 MLP 融合，再平均池化成分类向量。训练使用 focal loss、随机交换输入顺序和多分辨率采样，10 epochs 在 8 张 H100 上约 4 小时收敛。

03

实验Experiments

实验设置

配对消歧在 DG 和 VisymScenes 上报告 AP、ROC AUC、Prec@Recall=0.85、Recall@Prec=0.99 及 ms/pair，并与 DG-OG、DG++ 比较。下游重建覆盖 VisymScenes 258K images/149 sites/42 cities/15 countries、AerialMegaDepth 132K images/137 scenes、WRIVA 34 sequences 和 LaMAR 的 CAB/HGE/LIN；同时固定 COLMAP 或 GLUEMAP 其余阶段。

实验数字与比较

DG test 上 XDG 的 AP/ROC AUC/Recall@Prec=0.99/时间为 0.978/0.975/0.702/34.2 ms，DG++ 为 0.981/0.981/0.642/118.3 ms；VisymScenes 上 XDG 为 0.995/0.994/0.905/33.5 ms，DG++ 为 0.991/0.990/0.901/115.1 ms。LaMAR 三场景总消歧时间从 DG++ 的 49.93 h 降至 15.28 h，HGE 7,553 图像节省 10.85 h、LIN 9,319 图像节省 13.91 h；官方 HTML 表 1–5 给出这些数字。

消融/失败边界

DG 上从 camera-token variant 加 LoRA 后 AP/ROC AUC 从 0.9540/0.9511 提升到 0.9780/0.9750，时间仅从 32.9 增到 34.2 ms；去掉 camera token 改用 dense-token classifier 则回到 38.9 ms。作者明确展示了 WRIVA 的反例：在 COLMAP 管线中消歧会剪掉本已稀疏的匹配图，XDG 和 DG++ 都低于无消歧基线，说明 correspondence formation 可能比 false-edge removal 更关键。

局限与迁移Limitations & Transfer

局限与待核验

作者明确承认 XDG 在 LaMAR CAB 室内场景的宽松阈值上不如 DG++，且 DA3-Large 虽略提精度却把时延提高到约 2.4 倍。待核验项包括低纹理、极端视角和在线增量 SfM 中候选边分布变化，以及双向推理成本与图完整性阈值的联合调优。

原文摘要 · Abstract

XDG 将 Depth Anything 3 的 camera tokens 直接用于 SfM 中的 doppelganger 二分类，并用 LoRA 适配基础模型、轻量 MLP 完成判别。它在保持与 DG++ 接近的消歧和重建质量的同时，将大规模图像对处理成本降低三倍以上。

Visual aliasing, also known as the doppelganger problem, remains a key challenge for structure-from-motion (SfM): visually similar but physically distinct surfaces can produce incorrect image matches and degrade reconstruction quality. Previous work mitigates this issue with geometry-aware foundation-model features, but places a heavy transformer classifier on top of the backbone, making large-scale disambiguation expensive. We introduce XDG, an efficient visual disambiguation model designed for scalable SfM. Our key observation is that a 3D foundation model already performs the cross-view geometric reasoning necessary for visual disambiguation, so doppelganger classification should adapt the backbone representation directly rather than relearn pair reasoning in a separate heavy decoder. XDG fine-tunes Depth Anything 3 with lightweight LoRA adapters and repurposes its camera tokens as compact pair-level classification tokens. A compact MLP head predicts whether a candidate image pair observes the same 3D surface. Extensive experiments show that XDG provides a favorable accuracy-efficiency tradeoff: it remains competitive with the state-of-the-art disambiguation method across pairwise and reconstruction benchmarks and delivers more than a 3x inference speedup. On individual LaMAR scenes containing thousands of images, XDG saves more than 10 hours of visual disambiguation processing. Code is available at https://github.com/xtcpete/xdg.
