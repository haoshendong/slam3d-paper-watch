方法本质拆解 · What actually changed

是不是微调？

完全不训练。四个推理骨干（Qwen3.8-27B、GPT-4o、Opus 5、GPT-6 Astra）都是现成模型，方法只提供工具注册表、hooks、记忆结构与校验机制；论文把它定义为 training-free harness，并用“同骨干 + 同任务预算”的对照来证明收益来自 harness 而非模型能力。

有没有额外约束？

约束来自协议而不是损失函数：会话只能通过注册表中的工具读写记忆与执行移动；新会话必须继承交接与笔记；恢复尝试与原任务共享步数预算；停止前必须通过 pre-stop verification（若被判定未推进则重新发出动作），停止后必须做 post-stop certification 才能把完成写进记录。

推理/后端到底做了什么？

推理就是一个外层循环：新任务或恢复 → 开新会话 → 载入外部记忆（占据栅格、journal、房屋笔记）→ 多轮观察/查图/更正记忆 → 停止判定 → 认证 → 运行结束固化。没有梯度更新、没有策略网络、没有仿真器外的特殊后端；唯一的“后端”是记忆的写回与固化流程，以及可选的判官模型。

方法本质是什么？

本质是把“经验如何传递”从“塞进更长的上下文”改成“外部结构化记录 + 受检交接”：让新会话只继承可复用证据（访问过 vs 被排除的地点、未尝试的选项），并用认证机制阻断错误完成声明的扩散。它没有做的是：不训练记忆策略、不做地图后端优化、不改进底层 SLAM，因此它的收益上界仍由底层定位与判官质量决定。

输入=RGB 观测 + 由 SLAM 估计位姿构建的在线地图 + 历史任务记录与房屋笔记 + 前沿模型 API；改变的位置=跨会话的外部记忆结构与交接格式（模型权重不变）；动作=多轮工具调用式导航 + 结构化恢复交接 + 两段式完成校验 + 运行结束经验固化；直接效果=GOAT-Bench 83.7% s-SR / 36.9% e-SR、IR2R-CE 85.9% s-SR（同骨干独立会话分别为 65.1/13.6 与 68.4）。

01

桥接价值Bridge

桥接价值

这篇论文的价值在于把“具身导航”从单任务策略推进到跨任务的经验继承，而且明确只用 SLAM 估计位姿、不用仿真真值位姿就刷新了 GOAT-Bench 与 IR2R-CE 的公开最好成绩（83.7% s-SR / 36.9% e-SR 与 85.9% s-SR）。对我们“空间推理 → 具身决策”这一环，它给出了一条可复用的接口：状态估计与建图的输出并不直接喂给策略网络，而是进入一个可读可写的外部记忆（占据栅格 + 命名地点 + 任务记录），由多轮推理会话在导航过程中查询与更正。方法本身不含任何训练，因此可以低成本地接到我们现有的里程计/地图输出上做验证。

02

方法与模块Method

方法摘要

内层是一个多轮 agentic 会话：模型通过注册表里的工具读写地图、任务记录与房屋笔记，把自己的判断与观测对照后再行动；外层循环负责在任务之间与恢复尝试之间开新会话，但把记忆留在会话之外，使新会话能继承“哪些地点被访问过、哪些被证据排除、哪些选项还没试过”。记忆按生命周期与访问方式组织：工作记忆包含 SLAM 估计位姿构建的占据栅格、命名地点与照片、房间与楼层连接；任务记录组成 journal（ledger、任务交接、恢复笔记、完成校验结果）；运行结束时的固化把记录压缩成房屋级笔记。完成判定分两段：停止前的 pre-stop verification 与停止后的 post-stop certification。

可迁移模块

① 结构化恢复交接（structured recovery handover）：区分“访问过的地点”与“被证据排除的地点”、并保留尚未尝试的选项，比等长的普通摘要高 8.3 个百分点——这说明跨会话经验传递的核心是结构而不是长度，这条结论可以直接搬到我们的多轮调试/巡检 agent 里。② 两段式完成校验：停止前验证负责延长搜索，停止后认证负责修正记录，认证把记录准确率从 82.6% 提到 90.7%，说明“记录可信度”是一个可以单独度量的指标。③ 经验固化（run-end consolidation）：在连续部署中把 pooled s-SR 从 72.8% 提到 80.5%、SPL 从 36.5 提到 44.3，收益来自压缩而非新信息。④ 架构范式：“每次尝试开新会话 + 外部记忆持久化”，避免长上下文里过期目标与观测干扰当前任务。

边界与下一步Limits & Next Step

边界与风险

作者明确承认：记忆可靠性是限制——被判官错误接受的完成声明会传播进房屋笔记，而且更正一条记录不会自动更新它的副本、也不会验证其他空间陈述（附录 E 讨论剩余风险）。其它风险：全部评测在仿真内（Habitat 上的 GOAT-Bench 与 IR2R-CE 的 val-unseen 划分），成功判据是目标 1 m 内减速或停止，未见实机部署；结果依赖前沿模型 API 与判官模型，服务端版本变化会影响可复现性，成本也随多轮会话放大；“单会话连续进行”反而低于独立会话（54.9 对 58.9），说明长上下文与压缩本身有害，收益来自外部记忆而不是会话长度；恢复尝试共享原任务预算，预算设置会直接改变消融幅度。待核验：占据栅格由 SLAM 估计位姿构建，但正文未给出所用 SLAM 方法的配置与位姿误差量级（需查附录 B 的 backend 配置），因此“用 SLAM 位姿仍达 SOTA”这一结论的余量还无法定量；Astra/Opus 5 等模型在本次评测时的具体版本与 API 参数未在正文列出。

下一步实验

① 把我们的视觉/激光里程计或 PPP/INS 输出按“占据栅格 + 命名地点”的形式接到一个多轮 agent，做“有/无跨任务记忆”的最小 A/B，先验证记忆是否真的省步数。② 复现“结构化交接 vs 等长摘要”的对照（只改交接格式，其它全部固定），检验 8.3 点的增益在我们的巡检/调试任务上是否可迁移。③ 引入 post-stop certification 环节并单独度量“记录准确率”，量化它对错误传播的抑制效果。④ 记录 API 成本与步数预算的敏感性，为后续决定是否把这条链路产品化提供依据。

原文摘要 · Abstract

前沿模型现在可以靠多轮多模态推理与简单工具完成单次具身导航任务；但在连续任务之间，智能体还必须依赖一张持续演化的地图与早先的搜索记录，而这些记录可能不完整，甚至与新观测冲突。论文提出 NavHarness：一个免训练的具身 harness，把记忆处理变成导航循环的一部分。导航过程中，多轮 agentic 会话同时使用地图、任务记录与房屋知识，把它们与观测对照、并记录更正以指导动作；NavHarness 把这些经验跨会话保留下来，用于新任务或恢复尝试，并用结果校验与运行结束摘要支持后续复用。在 GOAT-Bench 上，它相对只用当前上下文的独立会话把 s-SR 提高 18.6 点（Astra）与 22.6 点（Opus 5）；在使用 SLAM 估计位姿（而非仿真真值位姿）的条件下，GPT-6 Astra 达到 83.7 s-SR 与 36.9 e-SR，在 IR2R-CE 上达到 85.9 s-SR。作者进一步发现：结构化的恢复交接优于等长摘要；在跨房屋的连续部署中，经验固化能带来超出“保留地图与任务记录”的收益。

Frontier models can now perform well on individual embodied navigation tasks through multi-round multimodal reasoning with simple tools. Across successive tasks, however, an agent must also rely on an evolving map and earlier search records, both of which may be incomplete or conflict with new observations. We present NavHarness, a training-free embodied harness towards lifelong navigation that makes memory processing part of the navigation loop. During navigation, its multi-round agentic session draws on maps, task records, and house knowledge, checking them against observations and recording corrections to guide its actions. NavHarness preserves this experience across fresh conversations for new tasks or recovery attempts, while outcome verification and run-end summaries support its later reuse. On GOAT-Bench, NavHarness improves s-SR over context-only independent sessions by 18.6 points with Astra and 22.6 with Opus 5. Using SLAM-estimated poses, NavHarness with GPT-6 Astra achieves state-of-the-art task success of 83.7 s-SR with 36.9 e-SR on GOAT-Bench and 85.9 s-SR on IR2R-CE. To understand these gains, we examine how experience is carried between sessions and find that structured recovery handovers outperform length-matched summaries. In extended deployments across houses, consolidation improves navigation beyond retaining maps and task records, with case studies showing how agents use earlier experience to interpret new goals, investigate unresolved questions, and resume failed searches. We suggest that progress towards lifelong navigation depends on how successive reasoning sessions build on prior experience, alongside improvements in single-task capability.
